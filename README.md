# AniMPV

An Android app for watching anime, reading manga, and streaming videos with mpv.

## Features

- **Anime Player**: Integrated with `ani-cli` engine and AniList for episode lists, covers, and details.
- **Manga Reader**: Browse and read manga with Comick search, genre filters, and chapter page viewer.
- **Fast Downloader**: Parallel HLS segment downloading with automatic retry.
- **MPV Player**: Hardware-accelerated video playback with custom controls, skip OP/ED buttons, and background playback.

## Download

Get the latest APK from [Releases](https://github.com/Riju2007123/ani-mpv/releases/latest).

## Build

```bash
./gradlew app:assembleDebug
```
